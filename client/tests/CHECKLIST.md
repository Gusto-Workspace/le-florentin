# Recette de la phase 3 — à compléter sur le Mac

## Installation / exécution
- [ ] `python3 scripts/download_photos.py` valide les cinq JPEG.
- [ ] `npm install` sans erreur.
- [ ] `npm run test:data` passe.
- [ ] `npm run build` passe sur cette version.
- [ ] `npm run dev` rend les cinq routes, sans erreur console majeure.

## Homepage validée conservée
- [ ] Arche du hero centré et de même forme ; expansion GSAP fluide.
- [ ] Menu ouvert/fermé pixel-identique ; Escape, liens, focus et scrollbar stable.
- [ ] Séquence geste vers assiette sans flash ; crème couvre le plateau fixe.
- [ ] Même rendu responsive et mouvement réduit.

## Pages intérieures
- [ ] `/menus` : catégories, plats, boissons, prix manquants, cartes de menus, liens vers sections ; état vide.
- [ ] `/gift-cards` : offres valeur/expérience ; sélection ; message et aperçu local ; aucune promesse d'achat.
- [ ] `/reservations` : date/convives/horaire préférentiel ; validation formulaire ; récapitulatif non transmis ; aucune disponibilité annoncée.
- [ ] `/contact` : numéro, adresse, courriel, itinéraire ; `mailto` génère un brouillon local ; aucune réservation par email.
- [ ] Menu global renvoie vers les quatre pages sans modifier son identité visuelle.
- [ ] Mobile 390px et 320px : aucune coupe de texte, défilement horizontal ni boutons invisibles ; tablette 768px.
- [ ] Réduction d’animations : formulaire et catalogue restent lisibles.

## Catalogues résistants
- [ ] `?demo=empty`, `minimal`, `many`, `long`, `hidden` sur `/menus` et `/gift-cards`.
- [ ] Aucun prix fictif présenté comme réel, aucun faux email ou paiement confirmé.
